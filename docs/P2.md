# P2 页面和接口契约

四个实际路由：
- /：项目列表、真实文档/任务/待审核统计、新建项目、项目时区。
- /projects/:projectId/import：UTF-8 TXT/Markdown上传或粘贴；标题、记录日期；固定模拟示例；去重反馈；分页文档列表。
- /projects/:projectId/review 和 /review/:documentId：选择文档，原文与行级证据，逐条审核、人工修订、拒绝，显示当前任务与本次确认值。
- /projects/:projectId/tasks：分页任务列表、当前页筛选、任务详情、人工编辑、变更前后值与来源回看；?task=UUID可直接打开任务。

前端 React + TypeScript + Vite，React Query 管理服务器状态；URL保存项目、文档和选中任务。localStorage仅保存最后选择的项目ID，不保存文档内容。
开发通过Vite同源/api代理；生产构建复制到Spring静态资源，深链接由明确的前端路由转发到index.html。API和静态资产路径不做通配转发。

新增只读能力：GET /api/projects/:id/documents?page=0&size=20；GET /api/projects的document_count/task_count/pending_count。
文档导入增加duplicate布尔反馈，不改变既有幂等键。没有数据库迁移、没有改动审核写事务。

409处理：保留审核或编辑草稿；刷新当前任务；展示最新版本和字段；用户明确核对后才采用新版本重新提交，绝不自动重试写请求。
按钮在请求期间禁用；同一建议的重复确认仍由后端唯一约束和事务提供最终保护。

运行：
PowerShell 7，根目录开两个终端：
1. ./scripts/Start-Backend.ps1 -Temporary
2. ./scripts/Start-Frontend.ps1
浏览器 http://127.0.0.1:5173 。临时数据库仅演示，退出后数据不保留。
持久数据库见README。构建整合：./scripts/Build-Web.ps1 -Package（先执行后端测试）。

模拟规则只支持固定指令，不是自然语言理解。页面显式提示。普通文本可归档并产生零条建议。
