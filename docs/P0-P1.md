# TraceFlow P0/P1 开发契约

## 范围
模块化 Spring Boot 单体、PostgreSQL 六张表、固定模拟抽取、JSON API。当前只绑定 127.0.0.1，未实现登录，不应直接部署到公网。P2 实现 UI；P3 接真实模型；P4 实现持久化队列、租约、重试和故障恢复。P1 的模拟抽取在导入事务内同步执行，无外部调用。

## 数据与事务
source_document 保存换行规范化后的不可变文本。去重范围为项目、SHA-256、参考日期、时区；同内容改变标题仍视为重复。不同来源但相同文本的语义合并不在此阶段。
导入时锁定项目：文档、模拟作业、建议全部原子写入。失败整体回滚。
审核时按项目、建议的顺序加锁：任务变更、task_change、建议状态全部原子提交。重复应用同一建议返回首次保存的历史结果，不执行新写入。请求必须通过字段校验；重复请求中的变更字段不被再次应用。
更新任务使用 version 条件，冲突返回 409，建议保持 PENDING。刷新当前任务并再次审核后，可提交新期望版本；历史记录保存本次审核输入。
项目锁为首版保守并发策略，串行化单项目写入，未来有真实瓶颈再细化锁粒度。
task_change 是追加历史，不是事件溯源引擎。手动修改也留历史。
负责人为姓名文本；截止日为 DATE；记录时间为 TIMESTAMPTZ；日期基准必须明确提供。无实体消歧或相对日期推断。

## 模拟协议
每行一个确定性样例，使用中文标点：
新增任务：接口联调；负责人：李明；截止：2026-11-12
更新任务：<任务UUID>；负责人：李明；截止：2026-11-15
不匹配的文本产生零建议，不调用 LLM。任务更新建议只引用当前项目的有效任务；原始引句与行号保存用于追溯。模拟协议不是自然语言理解能力。
审核采用完整字段替换：title 必填；assigneeName / dueDate 可为 null 表示未知。UPDATE_TASK 需要 expectedTaskVersion；CREATE_TASK 不接受该字段。
任务状态由手动 PATCH 修改，不允许审核 API 写入状态。

## 错误契约
400 INVALID_INPUT / INVALID_MOCK_INPUT / INVALID_TARGET / VERSION_REQUIRED
404 NOT_FOUND
409 VERSION_CONFLICT / PROPOSAL_CLOSED / TASK_LIMIT / TASK_ARCHIVED
列表 page 从0开始，size 范围1至100；任务按创建时间和ID排序。

## 测试门槛
真实 PostgreSQL 的 HTTP/服务集成测试：创建和更新闭环、证据和历史、重复导入和确认、并发确认、并发版本冲突、旧建议重新审核、跨项目拒绝与回滚、数据库故障回滚、拒绝终态、输入校验和无候选情况。
测试启动独立临时 PostgreSQL，不连接用户已有业务库；不以 H2 兼容模式替代 PostgreSQL。未通过测试不得声称阶段完成。
